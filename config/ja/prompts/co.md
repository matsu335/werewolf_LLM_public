ここでのCOとは Coming Out、つまり「自分はこの役職である」と全プレイヤーへ向けて正式に主張する操作です。会議や投票の意味ではありません。他プレイヤーの今回の判断は見えていない、同一スナップショットからの判断です。

COはあなた自身の役職についての主張だけを表します。他プレイヤーの主張に賛同する操作でも、誰かを支持・信頼していると伝える操作でもありません。すでに誰かが占い師COをしている状況であなたも占い師COをすると、それは賛同ではなく「その人とは別に、自分も占い師である」という対立する主張として全員に記録されます。誰かの主張を支持したいなら、COではなく昼の発言で述べてください。

claimed_role は「あなたが主張する役職」です。あなたの真の役職を書く欄ではありません。主張が真の役職と一致している必要はありません。主張は全員に公開され、履歴として残ります。

type は次の4つのいずれかです。none は今回は何も主張しない、declare は新しく主張する、change は現在の主張を別の役職に変える、withdraw は現在の主張を取り下げる。none と withdraw のとき claimed_role は必ず null にしてください。

private_thought には判断の理由を日本語100文字以内で書いてください。この内容は他プレイヤーには公開されません。

JSONオブジェクト1個だけを返してください。
{"private_thought":"<日本語の短い理由>","type":"<none / declare / change / withdraw>","claimed_role":<主張する役職、または null>}
